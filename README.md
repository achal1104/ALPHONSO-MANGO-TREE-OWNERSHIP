# AcresMoney – React frontend (demo)

```
npm install
npm run dev      # local preview
npm run build    # creates dist/
```

- Frontend only: no backend, payments, OTP or real auth.
- Register/Login data is stored in this browser's localStorage (demo, not secure).
- Photos: fill the `IMG` object at the top of `src/App.jsx` with your image URLs.
- Legal wording must be reviewed by a qualified CA/CS/securities lawyer before going live.
